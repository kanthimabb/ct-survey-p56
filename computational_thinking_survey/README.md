## 📊 ขั้นตอนที่ 3: การตั้งค่า Google Sheets เพื่อเก็บบันทึกข้อมูลวิจัยแบบอัตโนมัติ

เมื่อนักเรียนทำแบบสำรวจเสร็จสิ้น ระบบสามารถส่งคำตอบไปเก็บบันทึกใน Google Sheets ของคณะผู้วิจัยได้ทันที มีขั้นตอนดังนี้:

1. **เปิด Google Sheets ใหม่**:
   - เข้าไปที่ [sheets.google.com](https://sheets.google.com) แล้วกดสร้าง สเปรดชีตเปล่า (Blank Sheet)
2. **เปิดหน้าเขียนสคริปต์**:
   - ไปที่แถบเมนูด้านบน เลือก **ส่วนขยาย (Extensions)** &gt; **Apps Script**
3. **วางโค้ดสคริปต์**:
   - ลบโค้ดเดิมในไฟล์ `Code.gs` ออกทั้งหมด
   - คัดลอกโค้ดทั้งหมดจากไฟล์ `google_apps_script.js` มาวางแทนที่
   - กดปุ่ม **บันทึก 💾 (Save)**
4. **ทำการ Deploy เป็น Web App**:
   - กดปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy)** &gt; เลือก **การทำให้ใช้งานได้ใหม่ (New deployment)**
   - ในช่องประเภท (Select type) กดรูปเฟืองเลือก **เว็บแอป (Web App)**
   - ตั้งค่า **ผู้ที่มีสิทธิ์เข้าถึง (Who has access)** เปลี่ยนเป็น **ทุกคน (Anyone)** *(สำคัญมาก เพื่อให้นักเรียนส่งข้อมูลได้)*
   - กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** และอนุมัติสิทธิ์ (Authorize access)
   - คัดลอก **URL เว็บแอป (Web App URL)** ที่ได้มา (เช่น `https://script.google.com/macros/s/.../exec`)
5. **ใส่ URL ในเว็บไซต์แบบสำรวจ**:
   - เปิดหน้าเว็บ `index.html`
   - คลิกปุ่ม **⚙️ ตั้งค่าระบบ** ที่มุมขวาบน
   - วาง URL ที่คัดลอกมาลงในช่อง แล้วกด **💾 บันทึกการตั้งค่า**

## 🌐 ขั้นตอนที่ 4: การนำเว็บไซต์ขึ้นระบบออนไลน์ (เปิดให้นักเรียนทำผ่านมือถือ/แท็บเล็ต)

ผู้วิจัยสามารถนำเว็บไซต์ขึ้นออนไลน์ได้ฟรีหลายช่องทาง ดังนี้:

### ตัวเลือกที่ 1: นำขึ้น GitHub Pages (แนะนำ - ฟรีและเสถียร)
1. สมัคร/เข้าสู่ระบบ [GitHub.com](https://github.com)
2. สร้าง Repository ใหม่ (เช่น ชื่อ `ct-survey-p56`)
3. อัปโหลดไฟล์ `index.html`, `style.css`, `app.js` ขึ้นไป
4. ไปที่ **Settings** > **Pages** > เลือก Branch `main` แล้วกด **Save**
5. จะได้ URL เว็บไซต์สำหรับแจกให้นักเรียน เช่น `https://username.github.io/ct-survey-p56/`

### ตัวเลือกที่ 2: นำขึ้น Netlify Drop (ทำง่ายที่สุดใน 1 นาที)
1. เข้าไปที่ [app.netlify.com/drop](https://app.netlify.com/drop)
2. ลากโฟลเดอร์ `computational_thinking_survey` ทั้งโฟลเดอร์ไปวาง
3. ระบบจะสร้างลิงก์เว็บไซต์ออนไลน์ให้นำไปสร้างเป็น QR Code แจกนักเรียนทำแบบสำรวจได้ทันที!
